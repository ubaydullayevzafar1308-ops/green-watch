# Tashkent Green Watch 🌳🛰️

**Сегментация зелёного покрова и детекция его изменений в Ташкенте по снимкам Sentinel-2.**
Модель U-Net каждое лето (2019–2025) строит карту деревьев и кустарников, находит, где зелень
исчезла или появилась, и сводит результат по гексагонам H3 и районам. Всё доступно через
FastAPI и карту (UZ / RU / EN).

> 🇬🇧 English: [README.md](README.md)

## Зачем

В Ташкенте ведётся поштучный цифровой реестр деревьев ([green.tashkent.uz](https://green.tashkent.uz)).
Полевая инвентаризация даёт точные данные по каждому дереву, но она медленная и проходит город один раз.
**Спутник покрывает весь город каждый сезон.** Этот проект — прототип такого второго слоя:

- **где** сокращается зелень (карта горячих точек, площадь в гектарах);
- **как быстро** (временной ряд по гексагонам и районам);
- **что проверять в первую очередь**: список полигонов потерь с площадью и уверенностью модели,
  которые полевая команда или реестр может верифицировать.

## Как устроено

1. **Данные.** Sentinel-2 L2A из Microsoft Planetary Computer (бесплатно). Снимки июнь–август,
   облака маскируются попиксельно по SCL, учтён сдвиг +1000 у processing baseline 04.00,
   медианный композит. ESA WorldCover на той же сетке служит разметкой (деревья + кустарник = «зелень»).
2. **Датасет.** Разбиение по **пространственным блокам** 512 px с **буфером 64 px** между блоками
   разных выборок (пиксели буфера не входят ни в одну выборку), чтобы соседние пиксели не попадали
   одновременно в train и test. Train — **случайные кропы 256 px** целиком внутри train-блоков
   (500 за эпоху), val/test — фиксированные тайлы 256 px. Всё повторено на **3 пространственных фолдах**.
3. **Модель.** U-Net (ResNet-34) на 8 каналах: 6 полос + NDVI + NDBI. Loss: BCE + Dice с маской.
   Аугментации включают радиометрический шум, имитирующий разницу между годами. Порог подбирается на val.
   Обучение работает на Apple MPS.
4. **Бейзлайн.** Порог по NDVI, подобранный по лучшему F1 на пикселях train. Каждая метрика модели
   показывается рядом с ним.
5. **Детекция изменений.** Гистерезис вокруг порога модели `thr` из чекпойнта: потеря = P ≥ thr + 0.15
   до **и** P ≤ thr − 0.15 после, затем морфология и минимальная площадь 500 м². Флаг `confirmed` = в
   следующем году зелени тоже нет; считается только по пикселям, где в следующем году есть данные.
   Если данных меньше чем на 50 % патча или следующего года нет — `confirmed = null` («не проверено»).
6. **Агрегация.** Доля зелени по годам (каждый год — по своей маске валидных пикселей) и площадь
   потерь и прироста по гексагонам H3 и районам.
7. **Сервис.** FastAPI и карта на Leaflet без внешних CDN (работает в закрытой сети).

### Протокол оценки

| Выборка | Данные | Вопрос |
|---|---|---|
| `val` | 2021, отложенные блоки | ранняя остановка, порог |
| `test` | 2021, невиденные блоки | обобщается ли модель **в пространстве** |
| `test_time` | снимки и разметка **2020**, невиденные блоки | обобщается ли **во времени** (на этом держится детекция изменений) |

Все цифры — **среднее ± std по 3 пространственным фолдам** (разбиения блоков с seed 42 / 43 / 44).
`val` используется для ранней остановки и подбора порога, поэтому он завышен по построению; честные
цифры — `test` и `test_time`. Рабочая модель (`outputs/models/best.pt`) — фолд 0 (seed из конфига),
а не лучший по метрикам фолд.

## Результаты

Реальные данные: Ташкент, летние композиты Sentinel-2 (8 наименее облачных сцен за год), метки WorldCover
(зелень = классы 10 + 20). Обучение на 2021, `test_time` = 2020. **Среднее ± std по 3 пространственным
фолдам** (блоки 512 px, буфер 64 px, seed 42 / 43 / 44; 10–12 тестовых тайлов 256 px на фолд). Метрики
посчитаны **относительно WorldCover**, у которого самого точность ~75–77 %.

| Выборка | U-Net IoU | U-Net F1 | NDVI IoU | NDVI F1 |
|---|---|---|---|---|
| val (завышен: ранняя остановка + порог) | 0.439 ± 0.051 | 0.608 ± 0.049 | 0.255 ± 0.042 | 0.405 ± 0.054 |
| **test** (2021, невиденные блоки) | **0.463 ± 0.091** | **0.627 ± 0.089** | 0.305 ± 0.128 | 0.452 ± 0.163 |
| **test_time** (2020, невиденные блоки) | **0.404 ± 0.104** | **0.567 ± 0.112** | 0.297 ± 0.145 | 0.437 ± 0.189 |

U-Net лучше NDVI на **каждом** фолде: test IoU +0.127 / +0.210 / +0.136, test_time +0.097 / +0.164 / +0.060.
Разброс между фолдами большой (± 0.09–0.10 IoU): результат сильно зависит от того, какие кварталы попали
в test. В первой итерации (блоки 1024 px, без буфера, один сплит, test = 5 тайлов) U-Net проигрывал:
test IoU 0.177 против 0.216 у NDVI. Тестовые выборки разные, поэтому сравнивать стоит разницу U-Net − NDVI:
−0.039 → **+0.158** на test, +0.006 → **+0.107** на test_time.

Изменения 2020 → 2021 (модель фолда 0, порог 0.275 → гистерезис 0.425 / 0.125): 904 га кандидатов
в потери (2 963 пятна), 151 га прироста, доля зелени 12.0 % → 8.9 %. Это нужно читать осторожно: часть —
сдвиг модели между годами и смена версии WorldCover. Следующего года нет, поэтому у всех пятен
`confirmed = null` (не проверено).

## Быстрый старт

```bash
conda create -n greenwatch python=3.11 -y && conda activate greenwatch
pip install -r requirements.txt

make demo && make serve-demo   # офлайн-демо на синтетике → http://localhost:8000
make download                  # реальные данные Sentinel-2 + WorldCover
make pipeline                  # обучение и все расчёты
make serve                     # карта → http://localhost:8000
make test
```

## Честные ограничения

- **10 м/пиксель.** Видны зелёные *зоны* (парки, аллеи, дворы), а не отдельные деревья.
  Проект дополняет поштучный реестр, а не заменяет его.
- **Разметка — WorldCover, а не эталон** (общая точность около 75–77 %). Следующий шаг —
  ручная разметка тестовой выборки по Ташкенту.
- **Потеря зелени ≠ нарушение.** Разрешённая стройка тоже убирает зелень. Чтобы отличать нарушения,
  нужна сверка с разрешениями и кадастром, а для неё нужен официальный доступ к данным.
