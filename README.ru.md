# Tashkent Green Watch 🌳🛰️

**Сегментация зелёного покрова и детекция его изменений в Ташкенте по снимкам Sentinel-2.**
Модель U-Net каждое лето (2019–2025) строит карту деревьев и кустарников, находит, где зелень
исчезла или появилась, и сводит результат по гексагонам H3 и районам. Всё доступно через
FastAPI и карту (UZ / RU / EN).

> 🇬🇧 English: [README.md](README.md)

## Зачем

В Ташкенте ведётся поштучный цифровой реестр деревьев ([green.tashkent.uz](https://green.tashkent.uz)).
Полевая инвентаризация даёт точные данные по каждому дереву, но она медленная и проходит город один раз.
**Спутник покрывает весь город каждый сезон.** Этот проект — прототип такого второго слоя:

- **где** сокращается зелень (карта горячих точек, площадь в гектарах);
- **как быстро** (временной ряд по гексагонам и районам);
- **что проверять в первую очередь**: список полигонов потерь с площадью и уверенностью модели,
  которые полевая команда или реестр может верифицировать.

## Как устроено

1. **Данные.** Sentinel-2 L2A из Microsoft Planetary Computer (бесплатно). Снимки июнь–август,
   облака маскируются попиксельно по SCL, учтён сдвиг +1000 у processing baseline 04.00,
   медианный композит. ESA WorldCover на той же сетке служит разметкой (деревья + кустарник = «зелень»).
2. **Датасет.** Тайлы по 256 px, разбиение по **пространственным блокам**, чтобы соседние тайлы
   не попадали одновременно в train и test.
3. **Модель.** U-Net (ResNet-34) на 8 каналах: 6 полос + NDVI + NDBI. Loss: BCE + Dice с маской.
   Аугментации включают радиометрический шум, имитирующий разницу между годами. Порог подбирается на val.
   Обучение работает на Apple MPS.
4. **Бейзлайн.** Порог по NDVI. Каждая метрика модели показывается рядом с ним.
5. **Детекция изменений.** Потеря = P ≥ 0.6 до **и** P ≤ 0.3 после (гистерезис), затем морфология
   и минимальная площадь 500 м². Флаг `confirmed` ставится, если и в следующем году зелени нет.
6. **Агрегация.** Доля зелени по годам и площадь потерь и прироста по гексагонам H3 и районам.
7. **Сервис.** FastAPI и карта на Leaflet без внешних CDN (работает в закрытой сети).

### Протокол оценки

| Выборка | Данные | Вопрос |
|---|---|---|
| `val` | 2021, отложенные блоки | ранняя остановка, порог |
| `test` | 2021, невиденные блоки | обобщается ли модель **в пространстве** |
| `test_time` | снимки и разметка **2020**, невиденные блоки | обобщается ли **во времени** (на этом держится детекция изменений) |

## Быстрый старт

```bash
conda create -n greenwatch python=3.11 -y && conda activate greenwatch
pip install -r requirements.txt

make demo && make serve-demo   # офлайн-демо на синтетике → http://localhost:8000
make download                  # реальные данные Sentinel-2 + WorldCover
make pipeline                  # обучение и все расчёты
make serve                     # карта → http://localhost:8000
make test
```

## Честные ограничения

- **10 м/пиксель.** Видны зелёные *зоны* (парки, аллеи, дворы), а не отдельные деревья.
  Проект дополняет поштучный реестр, а не заменяет его.
- **Разметка — WorldCover, а не эталон** (общая точность около 75–77 %). Следующий шаг —
  ручная разметка тестовой выборки по Ташкенту.
- **Потеря зелени ≠ нарушение.** Разрешённая стройка тоже убирает зелень. Чтобы отличать нарушения,
  нужна сверка с разрешениями и кадастром, а для неё нужен официальный доступ к данным.
